Eagle Vision School Management System

Web-based records, attendance & grading system — built for an operating school

Case 01 · Solo Capstone

The Problem

Eagle Vision Basic School (~250 students, 13 classes, 12 teachers) tracked attendance and grading manually — slow to update and easy to get wrong.

What I Built

A full system for student records, attendance, class/subject management, and GES-standard grading (class score + exam score → grade 1–9), now used operationally by school staff.

Technical Highlights

  • Hardened all 27 PHP files against SQL injection using prepared statements
  • Fixed 222 XSS vulnerabilities across 19 files during a full security audit
  • Built login-attempt limiting — 5 attempts, 15-minute lockout with a live countdown
  • Designed a 9-table relational schema, including per-term student remarks
